===========================================
UR Ultrasonic Scan Project - Source Code Guide
===========================================

这个项目是一个基于ROS 2的超声波扫描系统，主要用于Universal Robots机械臂的工件扫描和处理。

===========================================
目录结构总览
===========================================
ur_ultrasonic_scan-master/
├── src/                                    # 源代码目录
│   ├── artifacts_workpiece_description/    # 工件描述包
│   ├── camera_use/                        # 相机点云处理包
│   ├── hello_moveit/                      # MoveIt运动规划包
│   └── mybot_description/                 # UR机械臂描述包
├── .gitignore                             # Git忽略配置
├── git_push.txt                           # Git操作脚本
├── output_problem.txt                     # 问题记录/配置片段
└── learn.txt                              # 本文件

===========================================
根目录文件说明
===========================================

1. .gitignore
   功能：Git版本控制的忽略配置文件
   内容：指定哪些文件/目录不应被Git追踪
   - build/     # ROS 2编译生成的构建目录
   - install/   # ROS 2编译生成的安装目录
   - log/       # ROS 2运行日志目录
   - *.swp      # Vim编辑器交换文件
   - *~         # 文本编辑器备份文件
   - .vscode/   # VS Code配置目录

2. git_push.txt
   功能：Git操作快捷命令脚本
   内容：包含常用的Git命令和Gazebo进程清理命令
   - git add .                            # 添加所有变更文件
   - git commit -m "..."                  # 提交变更
   - git push                             # 推送到远程仓库
   - killall -9 gzserver/gzclient/gazebo  # 强制终止Gazebo进程

3. output_problem.txt
   功能：问题记录和配置片段文件
   内容：包含ros2_control配置示例，用于解决机械臂控制问题
   - 定义了ur7e机械臂的硬件接口配置
   - 包含6个关节（shoulder_pan, shoulder_lift, elbow, wrist_1/2/3）
   - 配置了position/velocity/effort三种命令接口
   - 配置了初始位置参数

1. src/artifacts_workpiece_description/

子目录结构：
├── config/
│   └── joint_names_artifacts_workpiece_description.yaml

├── meshes/
│   └── workpiece_base_link.STL
│       # 工件的3D网格模型文件（STL格式）

├── urdf/
│   ├── artifacts_workpiece_description.csv
│   │   # URDF生成过程中的中间数据文件
│   └── artifacts_workpiece_description.urdf
│       # URDF机器人描述文件，定义工件的物理属性、视觉外观和碰撞模型

├── CMakeLists.txt
│   # 编译配置文件
├── package.xml
│   # ROS包声明文件
└── export.log
    # 导出日志文件

===========================================
项目工作流程
===========================================
1. 启动机械臂描述 → mybot_description
2. 启动MoveIt运动规划 → hello_moveit
3. 启动相机点云处理 → camera_use
4. 加载工件模型 → artifacts_workpiece_description

典型使用场景：
- 工件扫描：使用camera_use获取点云数据
- 路径规划：使用hello_moveit规划扫描路径
- 仿真验证：在Gazebo中加载工件进行验证

===========================================
编译说明
===========================================
1. 确保已安装依赖：ROS 2, MoveIt 2, PCL 1.13, VTK, OpenCV
2. 在工作空间根目录执行：
   colcon build --symlink-install
3. 运行前需source环境：
   source install/setup.bash
